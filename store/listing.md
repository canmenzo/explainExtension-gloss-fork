### Detailed description

```
Explain helps you understand what you are reading without leaving the page.

Select a word or passage, then choose Explain in the small action that appears next to your selection (or press Enter). A card opens beside the text with a short explanation of what the selection means in that context. If the selection names a person, place, organization, or work, the explanation identifies it when that is clear from the text.

How it works
- Open the Explain menu from the toolbar and choose "Use on this page". Explain only runs on the tab where you turn it on, and only after you ask it to.
- Add your own Google Gemini API key from Google AI Studio and choose a Gemini Flash model. The key is kept in browser session storage and is cleared when the browser closes.
- Select text and choose Explain. The card shows the selected text, a loading state while it waits, and the answer. If a request fails, the card explains why and offers Try again.
- Close the card with its close button, the Escape key, or a click outside it. Long answers scroll inside the card. The interface follows your system's reduced motion setting.

What is sent, and where
When you choose Explain, the extension sends the selected text, the paragraph around it, and the page title directly from your browser to Google's Gemini API, together with your API key. Nothing is sent to the developer, and there are no analytics, accounts, or servers of our own. The page's HTML and address are not sent. Answers are shown as plain text.

Your use of the Gemini API is governed by Google's terms. On Google's free tier, submitted content may be used to improve Google's products, and free access has rate limits. Review Gemini API pricing and data terms before you use it with sensitive material.

Requirements
- A Google Gemini API key (free or paid) from Google AI Studio.

Open source: https://github.com/canmenzo/explainExtension
```

## Privacy practices tab

### Single purpose

```
Explain has one purpose: when the user selects text on a web page and asks for it, show a short explanation of that text, generated by Google Gemini with the user's own API key.
```

### Permission justifications

**activeTab**

```
Used so the extension can run only on the tab where the user asks for it. When the user opens the Explain popup and chooses "Use on this page", activeTab gives temporary access to that one tab so the selection script can be added there. Explain does not request access to all sites and does not run on any page the user has not enabled.
```

**scripting**

```
Used to inject the extension's own bundled content script (content.js) into the active tab with chrome.scripting.executeScript, only after the user chooses "Use on this page" in the popup. The script shows the Explain action next to selected text and displays the explanation card. No remote or dynamically generated code is injected.
```

**storage**

```
Used with chrome.storage.session only, to keep the user's Gemini API key and chosen Gemini model for the current browser session so they do not have to re-enter it on every request. Session storage is held in memory, is not synced, and is cleared when the browser closes. Nothing is written to local or sync storage.
```

**Host permission: https://generativelanguage.googleapis.com/\***

```
Required to call the Google Gemini API (generativelanguage.googleapis.com, models/{model}:generateContent) from the extension's service worker when the user chooses Explain. This is the only network destination the extension contacts. The request carries the selected text, the nearby paragraph, the page title, and the user's API key, and returns the explanation shown to the user.
```

### Remote code

Answer: **No, I am not using remote code.**

```
All JavaScript, HTML, CSS, and the WebAssembly module (core.wasm, compiled from the Rust source in the repository) are bundled in the package and loaded from the extension itself via chrome.runtime.getURL. The 'wasm-unsafe-eval' CSP keyword is present only so the bundled core.wasm can be instantiated. The extension does not load scripts or wasm from any server and does not use eval. The only network request is a JSON call to the Gemini API, whose plain text response is displayed, never executed.
```
