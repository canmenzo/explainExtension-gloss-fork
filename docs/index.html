Understand what you read, right where you read it

Select a word or passage, right-click, and choose Explain. A small card opens beside the text with a short, plain explanation from Google Gemini.

Download from GitHubSee install steps

Free and open source. Uses your own free Google AI Studio key. No account, no analytics, no servers of ours.

How it works

Add a key once, then right-click to explain

  1. 1

    Add your key

    Click the Explain icon in the toolbar, paste your Google AI Studio key and click Save key. It is kept until the browser closes.

  2. 2

    Select and right-click

    Highlight a word, a phrase or a whole passage on any page, right-click it, and choose Explain.

  3. 3

    Read beside the text

    A card opens next to your selection and the explanation streams in as Gemini writes it. Close it with Esc or a click outside.

Explained in context

Explain sends the paragraph around your selection too, so a word is explained the way this page uses it.

Streams as it writes

The answer appears word by word as Gemini writes it. Long answers scroll inside the card, so the page stays where it was.

Quiet until asked

Nothing runs on a page until you choose Explain from the menu, and then only on that tab.

Clear when it fails

If Gemini is busy or the key is wrong, the card says so in plain words and offers Try again.

Privacy

Your text goes to Google, and nowhere else

Explain has no servers, no account and no analytics. When you choose Explain, your browser sends the request straight to Google's Gemini API with your own key. Nothing passes through us.

What is sent

  • The text you selected
  • The paragraph around it
  • The page title
  • Your API key, to authenticate the request

What is never sent

  • The page address
  • The page's HTML
  • Anything from tabs where you did not choose Explain

What is stored

  • Only your API key, in browser session memory
  • Cleared when the browser closes
  • Answers are shown, then discarded

Google's free tier. Requests are processed under Google's terms. On the free tier, Google may use submitted content to improve its products; its paid tier says it does not. Avoid explaining sensitive text on a free key. Read the full privacy policy.

Install

Ready in about two minutes

  1. Download the ZIPGet explain-chrome.zip from the latest release and unzip it.
  2. Open the extensions pageType chrome://extensions in the address bar and turn on Developer mode in the top right.
  3. Load unpackedClick Load unpacked and choose the unzipped folder, the one that contains manifest.json. Pin Explain from the puzzle piece menu so its icon stays in the toolbar.
  4. Add your keyClick the Explain icon and follow Get a free key to Google AI Studio. Paste the key and click Save key. Then select text, right-click and choose Explain.
Firefox. Download explain-firefox.zip from the same release and unzip it. Open about:debugging#/runtime/this-firefox, click Load Temporary Add-on and pick manifest.json in the unzipped folder. Firefox removes temporary add-ons when it closes, so repeat this after a restart. Needs Firefox 140 or newer.
Chrome Web Store. A store listing is coming soon, with one-click install and automatic updates. Until then, the GitHub release is the way in.

FAQ

Questions people ask

Does it cost anything?

Explain itself is free and MIT licensed. The Gemini key is yours: creating one in Google AI Studio is free, and Google's free tier covers light reading with rate limits that depend on your account. If you set up billing with Google, Google charges you directly. See Gemini API pricing.

What exactly is sent, and to whom?

Only when you choose Explain: the selected text (up to 12,000 characters), the paragraph, list item, heading or table cell around it (up to 5,000 characters), the page title (up to 300 characters) and your key. It goes straight from your browser to generativelanguage.googleapis.com. The page address and HTML are never sent.

Why do I paste my key again after restarting the browser?

The key is kept only in the browser's session storage, which lives in memory and clears when the browser closes. Explain never writes it to disk. That is a deliberate trade for a little extra typing.

What if I choose Explain before adding a key?

The card says to add your key first, and where the browser allows it, the key popup opens for you. Paste the key, click Save key and choose Explain again.

Which browsers are supported?

Chrome, and Firefox 140 or newer, on desktop. Other Chromium browsers that can load unpacked extensions may work with the Chrome build, but they are not tested.

Which model writes the answers?

Gemini 3.8 Flash. Explain calls the model directly and does not run a Google Search, so answers come from the text you selected, the paragraph around it and what the model already knows.

Can it read every page I visit?

No. Explain has no access to your sites until you choose it from the right-click menu. That grants it the current tab only, through the browser's active tab permission.

Is it in the Chrome Web Store?

Not yet. The listing is coming soon. For now, install it from the GitHub release as described above.
